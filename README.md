# Cotizador de Servicios

Aplicación web que calcula el precio de un servicio según el tipo elegido y la cantidad de horas.

🔗 **Demo:** https://martinleiva02.github.io/CotizadorServicios/

## Cómo funciona
1. Elegí un servicio de la lista.
2. Ingresá la cantidad de horas.
3. Tocá **Cotizar** y el resultado aparece en pantalla.

## Cálculo
Cada servicio tiene un valor por hora. El total se calcula multiplicando ese valor por la cantidad de horas ingresadas.

## Tecnologías
